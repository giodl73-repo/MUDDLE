# Corresponding software and original grants

The source ZIP preserves exact committed bytes/modes for root Cargo.toml/lock,
LICENSE, all seven original native crates, the retained docs/rune software
contract fixture and this browser companion. It is the complete buildable
software workspace needed for native controls, original CLI, native tests and
browser WASM. It is not a full repository, authoritative BANISH/AMAZE game
distribution, offline vendor pack or archive of policy/review/wave documents.

Existing embedded demo narratives and original native code stay unchanged. The
original LICENSE retains separate MIT software/ordinary software-documentation
and CC BY-NC original non-software content grants. No prior grant is withdrawn;
third-party terms remain their own. The pinned external RUNE dependencies and
registry dependencies are downloaded by Cargo. Browser dependency notices and
Rust runtime notices accompany compiled WASM; Node tooling is build-time only.

All native crates are included to preserve the original root workspace and its
tests, including the native Macroquad renderer. Existing root-lock macroquad
0.4.14 advisory GHSA-gg76-hg3v-5q6c remains open; its code is absent from the
browser dependency closure. Shipping corresponding source is not native security
certification, a new native binary release, or graphics/product adoption parity.

Build requires the documented pinned compiler/bindings, network access for
dependencies and no TRACKER-relative paths or Git ancestry. Release verification
rebuilds this ZIP outside Git in a path with spaces and independently repeats
native/WASM controls, native CLI save/transcript bytes and browser behaviors.
Cross-directory/platform binary identity is not claimed; both hashes are retained.
